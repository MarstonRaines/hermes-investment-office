# ADR-009：手工账本与最终产品形态

- 状态：接受（第 7 条导航结构已由 ADR-011 取代）
- 日期：2026-08-24
- 决策来源：用户在最终产品 QA 中的明确选择

## 背景

早期冻结文档把 Dashboard 定义为完全只读，并保留了券商账户/交易执行的远期术语。最终产品明确不连接券商；用户需要在同一 Dashboard 中维护自己手工输入的真实持仓、现金和实际交易结果。

## 决策

1. 系统永久不集成券商账户、订单路由、资金划转或自动执行。
2. REAL 组合代表用户的本地手工账本，不代表券商侧实时账户。
3. 期初持仓由用户填写标的、数量、平均成本和持有日期；当前现金单独填写。
4. 后续买入、卖出、分红、费用和现金变动由用户手工登记；持仓始终从不可变流水重放派生。
5. Hermes 最高只能创建交易建议。批准/拒绝和实际完成登记属于本机人工 `ACCOUNT_WRITE`；实际完成必须填写日期、价格、数量和费用，且不会调用任何外部交易接口。
6. Dashboard 的事实与指标读取仍只通过 Backend REST；人工写入也只通过受限 REST，不连接数据库或数据卷。
7. 当时确定 Dashboard 采用中文优先、信息密集、跟随系统主题的四页结构；具体一级导航随后由 ADR-011 统一为“今日、标的、组合、问 Hermes”。首屏顺序仍为系统/新鲜度、关注事项、简报、观察池/组合。
8. 初始观察池为 `510300.SH`、`513650.SH`、`512890.SH`，初始化只创建身份和观察关系，不创建示例行情。
9. 外部代理是显式依赖但由系统外管理；不可用必须表现为 `WARNING`、`STALE` 或 `FAILED`。

## 自动化

- Backend：工作日 07:30（Asia/Shanghai）。
- 每日简报：工作日 09:00。
- 周度回顾：周六 10:00。
- 季度回顾：1、4、7、10 月 1 日 10:00。
- 备份：每日 03:00；保留 30 份每日备份和 12 份周备份。

## 与旧文档的关系

本 ADR 只覆盖旧文档中“Dashboard 完全只读”“未来券商接入”“不创建产品默认对象”等产品形态描述；一级导航以 ADR-011 为准。以下冻结约束继续有效：Backend 是事实与计算平面、Dashboard 不直连数据库、MCP 无 `ACCOUNT_WRITE`、REAL 写入必须人工、append-only 审计、freshness 门禁和无 Broker Execution。
