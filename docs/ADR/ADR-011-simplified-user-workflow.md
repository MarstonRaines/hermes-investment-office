# ADR-011：以标的为中心的简化操作流程

- 状态：Accepted
- 日期：2026-08-25
- 取代范围：ADR-010 中“第五项导航”的界面数量结论，以及旧 Dashboard 文档中的五入口信息架构

## 背景

原有“今日、观察池、持仓、回顾、问 Hermes”把同一研究对象拆到多个入口。新增标的还要求用户填写可由代码推断的市场和资产类型，初始化失败后只留下空详情页。全局日期又同时改变多个页面，导致当前状态和历史快照容易混淆。

## 决策

1. 一级导航固定为“今日、标的、组合、问 Hermes”。
2. “观察池”降为“标的”页内筛选；研究、估值、事件和来源都从同一标的详情进入。
3. 新增标的只要求代码和名称。Backend 自动推断沪深市场与股票/ETF 类型，建立 Provider 映射，并依次初始化行情、财务或 ETF 资料、披露与公司行动、基础观点。
4. 初始化按阶段返回真实状态；失败不回滚已经完成的阶段，标的详情提供显式“补齐资料”入口。
5. 默认始终显示最新状态。历史日期只在标的详情和组合页局部开启，历史模式禁止任何写入。
6. 股票客观估值由 Backend 事实确定性生成；主观情景估值必须由用户提供并确认价值、概率与依据。
7. Hermes 会话自动保存。将回答用于研究笔记、观点版本、估值或跟踪事项时，必须先选择标的、显示可编辑预览并由用户确认。
8. 系统不连接券商。组合持仓、现金、买卖、分红和费用全部来自用户手工维护的仅追加账本。

## 结果

用户从“今日”处理问题，从“标的”完成单证券研究，从“组合”维护现实账本，从“问 Hermes”进行开放式研究。历史和写入责任均在发生位置清晰呈现，不再依赖全局状态或独立“回顾”页面。
